# Master Mobile Photography: Capturing Professional Photos with Your Smartphone

**Course code:** TGS-2026064718
**TSC:** Camera Operations (MED-MPN-3034-1.1)  
**Version:** v12.0 · 19 August 2026

This public learner repository contains the current slide deck, Learner Guide, Lesson Plan and eight self-contained real-use-case activity packs. Detailed procedures live in the Learner Guide and activity folders; the PowerPoint remains visual and concept-led.

## Learning outcomes

- LO1: Set up a mobile phone camera for shooting and interpret a shot plan.
- LO2: Perform basic mobile photography while meeting safety requirements.
- LO3: Apply framing and composition techniques using a mobile phone camera.
- LO4: Enhance visual quality and effects using capture and editing controls.

## Activities

See [`activities/`](activities/README.md). Each folder includes a guide, printable checklist, cheat sheet, evidence log and sample photograph.
