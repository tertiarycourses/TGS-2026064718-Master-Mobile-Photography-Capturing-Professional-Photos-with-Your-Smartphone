# Activity 8 Cheat Sheet — Edit and Deliver a Tourism Campaign Set

- Select → crop/straighten → tone → colour → detail → export
- Aspect ratios: landscape 16:9 · square 1:1 · vertical 9:16
- Reduce an adjustment when the edit becomes the first thing viewers notice

## Universal capture loop

**CLEAN → STABILISE → FRAME → FOCUS → EXPOSE → CAPTURE VARIATIONS → REVIEW**

## Field reminder

The control names may vary by device. Judge the image and the evidence, not whether the menu label matches another phone.
