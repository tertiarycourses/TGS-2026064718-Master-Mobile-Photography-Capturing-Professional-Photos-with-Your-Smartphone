# Activity 8 Guide — Edit and Deliver a Tourism Campaign Set

**Scenario:** A local travel business needs six consistent photographs for a web page, square social post and vertical story.

**Tools:** Built-in editor, Lightroom Mobile or Snapseed; file manager/cloud folder

**Deliverable:** Six-image final set, before/after comparisons, export matrix and critique record

## Detailed step-by-step
1. Select six frames that cover place, people/action and detail without duplication.
2. Duplicate originals or work non-destructively before editing.
3. Straighten and crop for the intended aspect ratio while protecting key content.
4. Correct exposure, highlights, shadows and contrast before changing colour.
5. Correct white balance and apply one restrained, consistent colour treatment.
6. Apply selective healing only to temporary distractions—not documentary facts.
7. Add light sharpening at final size and avoid halos or excessive noise reduction.
8. Export landscape, square and vertical versions using the export matrix.
9. Compare before/after images for realism, consistency, artefacts and privacy.
10. Run a peer critique and record one angle/capture improvement for a future reshoot.

## Acceptance criteria
- [ ] Six images are visually consistent
- [ ] Edits retain natural texture and colour
- [ ] Exports match the named channels
- [ ] Critique contains a specific evidence-based improvement

## Troubleshooting

- Missing control: use the closest native mode and document the limitation.
- Soft result: clean, stabilise, re-focus and repeat.
- Clipped highlight: lower exposure or change the light/camera position.
- Unsafe/unauthorised capture: stop and use a controlled substitute.
